# OurSpace
> Authors: [Sabaipon Phimmala](https://github.com/bphimmala), [Emily Hix](https://github.com/emilyhix), [Linda Ghunaim](https://github.com/lindgh),  [Glider Mapalad](https://github.com/gmapa002)

OurSpace is a mobile application that allows students to connect with others with similar studying habits and course work. Create and edit a profile, swipe to match with other students, and message!

OurSpace is built using Flutter and utilizes a Firebase backend to facilitate user authentication, profile creation, and instant messaging. Other users are served to the client by our matching algorithm that considers graduation year, college, and major.
